For this game jam entry I worked together with Ape Tavern once again, I was responsible for the environment art, VFX, branding and some shader work.

I created a stop-motion shader for the environment assets to give them a more hand-made feel. It uses a 2x2 flipbook with 4 slightly different brush stroke grunges, then a World Position Offset wobble that snaps the mesh to a slightly different shape.

I had a lot of fun experimenting with some hand-drawn 2D elements as well, I've never really been confident about my drawing abilities, but I know that if I keep drawing it'll only get better.
